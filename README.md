# TRAN NAM PHONG – Portfolio Personnel

Site web portfolio personnel présentant mes projets, compétences et profil en développement web.

## 🚀 Technologies utilisées
- HTML5  
- CSS3  
- JavaScript  

## ✨ Fonctionnalités
- Design moderne et responsive  
- Interface claire et structurée  
- Interactions dynamiques avec JavaScript  

## 🎯 Objectif
Ce projet est un travail personnel servant d’exercice et de démonstration de mes compétences en développement web.  
Il s’agit d’une version simple, construite uniquement avec du code HTML, CSS et JavaScript, sans framework ni bibliothèque externe.

## 🛠️ Installation et utilisation
1. Cloner le dépôt : https://github.com/namphongtr/Portfolio/
2. Ouvrir le fichier `index.html` dans un navigateur.
